## 第 1 题（空安全：`?.` 与 `??`）

**题目**

```dart
void main() {
  String? a;
  print(a?.length);
  print(a?.length ?? 0);
  a = 'dart';
  print(a?.length ?? 0);
  print(a!.length);
}
```

| 要素 | 内容 |
|---|---|
| 我的答案 | null / 0 / 4 / 4 |
| AI 参考答案 | null / 0 / 4 / 4 |
| 复核结论 | 全对。`?.` 为 null 时短路返回 null；`??` 在左侧为 null 时取兜底值；赋值后 `?.length` 与 `!.length` 都得到 4。已掌握空安全三件套的基本行为 |

## 第 2 题（空安全：`??` 的触发条件）

**题目**

```dart
void main() {
  String? name;
  String? other = 'x';
  print(name ?? other ?? 'none');
  name = '';
  print(name ?? 'none');
  print(name.isEmpty);
}
```

| 要素 | 内容 |
|---|---|
| 我的答案 | x / （空行） / true |
| AI 参考答案 | x / （空行） / true |
| 复核结论 | 全对。关键点：空字符串 `''` 不是 null，所以 `??` 不触发，第二个 print 输出空行。避开了"空串≈null"这一高频误区 |

## 第 3 题（命名参数）❌

**题目**

```dart
String tag({required String name, String prefix = '同学', int? grade}) {
  return '$prefix$name${grade == null ? '' : '（$grade 级）'}';
}

void main() {
  print(tag(name: '李华'));
  print(tag(name: '王芳', grade: 2));
  print(tag(prefix: 'Prof.', name: 'Chen'));
}
```

| 要素 | 内容 |
|---|---|
| 我的答案 | 李华 / 王芳2级 / Chen |
| AI 参考答案 | 同学李华 / 同学王芳（2 级） / Prof.Chen |
| 复核结论 | 三处全错，同一原因：漏看返回值开头的 `$prefix$name` 拼接。prefix 是命名参数，没传时用默认值 `'同学'`，传了 `'Prof.'` 就用它，**任何一次调用都会拼进结果**。教训：命名参数题必须把函数体整个读一遍，逐个确认每个参数的去向，不能只看调用处传了什么 |

## 第 4 题（整除与插值）❌

**题目**

```dart
void main() {
  print(7 ~/ 2);
  print(7 / 2);
  print(7 % 2);
  print('${7 ~/ 2}${7 % 2}');
  print('总分${(1 + 2) * 3}');
}
```

| 要素 | 内容 |
|---|---|
| 我的答案 | 3 / 3.5 / 1 / ？ / 总分：9 |
| AI 参考答案 | 3 / 3.5 / 1 / 31 / 总分9 |
| 复核结论 | `~/`、`/`、`%` 三个运算符已掌握。错两处：① `'${7 ~/ 2}${7 % 2}'` 是**连续两个插值**，第一段插出 `3`、第二段插出 `1`，紧挨着拼成字符串 `31`（不是运算得 31，也没有空格）；② 源码字符串 `'总分${(1 + 2) * 3}'` 里**没有冒号**，输出是 `总分9`，我脑补了分隔符。教训：插值题从左到右逐段插、原样拼接，输出必须严格照源码字符 |

## 第 5 题（综合：找错）❌

**题目**

```dart
void main() {
  var count = 10;
  count = '十';
  String? msg;
  if (msg) {
    print('有值');
  }
}
```

| 要素 | 内容 |
|---|---|
| 我的答案 | 不知道 |
| AI 参考答案 | 共 2 处编译错误：① `count = '十';`——`var count = 10` 已将 count 推断为 int，不能再赋 String（var 只是省写类型，不是什么都能装，那是 dynamic）；② `if (msg)`——Dart 的 if 条件必须是 bool，msg 是 String?，应写 `if (msg != null)` 或 `if (msg!.isNotEmpty)` |
| 复核结论 | 完全没掌握，需重点补。对应指南两处翻车警告：var 推断后类型锁死；条件判断里字符串不能当布尔用。此题型即雨课堂"错误定位"题原型，牢记两条铁律：**var 类型锁死；if 条件必须 bool** |
